# 水深・離岸距離マップ

日本近海（東経122〜150度・北緯24〜46度）の水深と、陸からの距離を表示するWebアプリです。

- 地図を押すと、その地点の水深・陸からの距離・最寄りの陸（市区町村）を表示します
- 現在地ボタン（◎）で、GPSの位置の水深と距離を追いかけて表示します
- 一度見た場所は端末に保存され、圏外でも表示できます。「全国を保存」でまとめて保存もできます
- iPhoneでは Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます

航海や工事の根拠には使わないでください。海上保安庁の海図などを使ってください。

## 出典

- 水深：NOAA National Centers for Environmental Information, ETOPO 2022 15 Arc-Second Global Relief Model（約460m格子）
- 陸の地図：国土地理院 地理院タイル（淡色地図）を加工して作成
- 海と陸の判定・市区町村名：「国土数値情報（行政区域データ）」（国土交通省）を加工して作成
- 地図ライブラリ：Leaflet 1.9.4（BSD-2-Clause）
